### 🟠 设计债 (本版接受, 已写进已知限制)

| # | 问题 | 为什么本版不改 |
|---|---|---|
| 9 | 每轮对话起一个新 Hermes 进程 (2-4 秒启动开销) | 改走 WebSocket JSON-RPC 需要先摸清 gateway 的 RPC 契约 (方法名与参数 schema 不在公开文档里), 风险高于收益。V0.1 先保证可靠。 |
| 10 | 前台 profile 与后台工程 profile 记忆隔离 | 设计如此: 管家归管家, 工程归工程。 |
| 11 | 启动脚本 `.bat` 必须是 GBK/ASCII (不能 UTF-8) | cmd.exe 原生按 GBK 解读脚本内容。文件内容已设计成全英文 + 路径无中文, 实测两种编码都能跑。 |
| 12 | 前台没有多轮历史 UI (只显示最近一条) | 极简优先。要看全部历史应去后台看板。 |
