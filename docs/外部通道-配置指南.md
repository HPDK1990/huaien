# 外部通道 —— 配置指南

> 三条路, 各自要你亲手做哪一步、能不能成、有什么坑。
> 先看结论, 再看细节。

---

## 一览

| 通道 | 状态 | 你的动作 | 能干什么 | 坑 |
|---|---|---|---|---|
| **飞书** | 🟡 **出站已通，入站缺权限** | 补 2 个 tenant scope + **重新发布版本**，再发一条消息 | 异地发消息、收汇报 | 缺 `im:message.p2p_msg`（私聊入站）/ `im:message.group_at_msg`（群 @ 入站）|
| **手机浏览器 (局域网 PWA)** | **本项目已实现** | 双击 `怀恩手机端.bat`，用手机连同一 WiFi 打开它 | 手机上跟怀恩说话，可"添加到主屏幕" | 只能同一个 WiFi；链接带口令，别转发 |
| **微信个人号** | 官方支持，**待你扫码** | `hermes gateway setup` → 选 Weixin → 扫码 | 微信私聊发消息 | **群聊大概率不通**（腾讯 iLink 的限制） |
| **企业微信** | 需要企业组织 | 你没有 → 走不通 | — | 需要 WeCom 组织账号 + 管理后台建 Bot |
| **公网直连** | 🔴 **已定论：走不通** | 无需试了 | — | **双层 NAT**：光猫(mifi)上行是 `192.168.x.x` 私网，PC 没有公网 IP；路由器 UPnP / NAT-PMP 都没有；防火墙该网卡是 Public 档 |

## ① 飞书（已在跑，只差你发一条）

**现状实测**：

```
gateway_state.json : feishu state=connected
agent.log 末条     : 12:09:20 connected to wss://msg-frontier.feishu.cn/ws/v2
state.db 里 feishu 的会话记录: 1 条  →  以前连过，chat_id 已建立
```

**出站我已实测通了**：`hermes send "..." -t feishu:<FEISHU_CHAT_ID>`
→ `rc=0 sent`（文字 / 图片 / 文档 / markdown 表格 **四种都发得出去**）。

**但入站还差 2 个权限**（`im:message.p2p_msg` 私聊入站、`im:message.group_at_msg` 群 @ 入站），
缺了的话你发消息给机器人，它收不到。

**你要做的**：

1. **补权限**（一次性授权链接，tenant scope）：
   ```
   https://open.feishu.cn/app/<FEISHU_APP_ID>/auth?q=im:chat:readonly,im:message:send_as_bot,im:message.p2p_msg,im:message.group_at_msg
   ```
2. 🔴 **授权后必须重新发布版本**，否则权限不生效 ——
   开放平台 → 版本管理与发布 → 创建版本 1.0.1 → 申请发布
3. **复验权限**：跑 `scripts/probe_feishu_scopes.py`，期望 `MISSING` 列表为空
4. 在飞书里给 **Hermes-work** 机器人发一句话（比如 `/help`）
5. 看入站日志：`tail -30 "%LOCALAPPDATA%\AppData\Local\hermes\logs\agent.log" | findstr /i lark`

**怀恩产出的文件怎么送过来**（两条路，都有实测）：

```bash
# 路 A: agent 在回复里写 MEDIA:/绝对路径 —— agent 自己就能触发
hermes send --to feishu:<FEISHU_CHAT_ID> "怀恩写好了。\n\nMEDIA:<PROJECT_ROOT>\docs\shot_new.png"

# 路 B: 项目里的 report.py 直接推 (不依赖 agent 记得写 MEDIA:)
python scripts/report.py --say "任务做完了" --file <PROJECT_ROOT>\docs\shot_new.png
```

两种都实测通过（图片、文档、markdown 表格全部 `sent`）。

**顺带设个 home channel**（已设：`FEISHU_HOME_CHANNEL=<FEISHU_CHAT_ID>`）。

> ⚠️ **实测坑**：设了 home channel 之后，`hermes send` **仍然要求显式 `--to`**
> （报 `--to PLATFORM[:channel[:thread]] is required`）—— 那个配置对 send 不生效。
> 所以项目里的 `scripts/report.py` 自己解析目标：先读 `FEISHU_HOME_CHANNEL`，
> 读不到再从 `state.db` 的 `gateway_routing` 里找用户的 DM chat_id。

**已修的一个坑**：`gateway_routing` 表里原本有 **74 条悬空记录**（指向已被清理掉的本地会话），
导致平台消息落库时撞外键（日志里是 `Mirror failed ... FOREIGN KEY constraint failed`）。
**已备份后清掉，复验悬空 = 0**（备份在 `logs/memory_backup/gateway_routing_备份-*.json`，
清理脚本 `scripts/cleanup_routing.py`）。

**怎么确认通了**：

```bash
# 有回复 = 通道正常
hermes -p huaien sessions list     # 应该多出一条飞书会话

# 或者直接看日志
tail -30 "%LOCALAPPDATA%\AppData\Local\hermes\logs\agent.log" | findstr /i lark
```

**注意**：飞书机器人回的是 **default profile**（后台那个），不是 `huaien`。
想让它也用怀恩的人格，得另配 —— 现阶段先当"第二个入口"用。

## ② 手机浏览器（局域网 PWA）—— 本项目已实现

**为什么要这个**：真写手机 App 要签名/上架，不现实。PWA 是**能落地的手机软件** ——
浏览器打开一次，"添加到主屏幕"，之后跟原生 App 一样有图标、全屏、无地址栏。

**你要做的**：

1. 双击桌面上的 **`怀恩手机端.bat`**
2. 窗口里会打印两行地址：
   ```
   本机:   http://127.0.0.1:8765/?t=xxxxxxxx
   手机:   http://192.168.x.x:8765/?t=xxxxxxxx
   ```
3. 手机连**同一个 WiFi**，浏览器打开"手机"那行
4. 手机浏览器菜单 → **添加到主屏幕**

**已实测**：

| 项 | 结果 |
|---|---|
| 错口令访问页面 | HTTP 403 ✅ |
| 对口令访问页面 | 200 ✅ |
| manifest / sw.js / icon | 全部 200 ✅（PWA 三件套齐） |
| 真实问一句 | 10.8 秒拿到回复 ✅ |
| 图片显示 | agent 生成的图能在手机上看（Web 版有 `<img>`） |

**安全提醒**：那个 `?t=xxxxxxxx` **等同于你的电脑权限**（能指挥怀恩动你的文件）。
**不要转发给任何人**，也别在群里贴。

**电脑关机/换网络就要重新开一次**（地址里的 token 每次随机生成）。

## ③ 微信个人号（待你扫码）

**好消息**：Hermes **官方支持**个人微信，用腾讯的 **iLink Bot API**，
扫码登录、**不需要公网 IP**、不需要 webhook（长轮询）。

**坏消息**（官方文档明说）：iLink 登录后 Hermes 拿到的是一个**独立的机器人身份**
（形如 `xxxx@im.bot`），**不是你的普通微信号**。后果：

- 这个机器人**拉不进普通微信群**
- 普通微信群的消息（包括 @ 你的号）**基本收不到**
- **私聊（DM）才可靠**

**你要做的**：

```bash
# 交互式向导, 选 Weixin, 然后用手机扫终端里的二维码
hermes gateway setup

# 前置依赖
python -c "import pm; pm.sync_venv(['messaging'], explicit=True)"
```

**装完确认**：

```bash
hermes gateway status                      # 平台列表里应有 weixin
hermes -p huaien sessions list             # 微信会话会出现在这里
```

**我的建议**：**值得试**（5 分钟的事），但**别把它当唯一通道** ——
群聊不通是腾讯的限制，不是 Hermes 能绕过的。

## ④ 公网直连 —— 已定论：走不通（不用再试了）

**实测证据**：

| 项 | 结果 |
|---|---|
| 出口 IP | `117.136.38.164`（中国移动段，**不是你的**） |
| **网络拓扑** | 🔴 **双层 NAT**。光猫（mifi）上行是 `192.168.x.x` 私网 → **PC 没有独立公网 IP** |
| 验证方式 | `tracert` 第一跳 + `arp` 表 + mifi 后台 `g_platformName="mifi"` |
| 路由器 UPnP | **没有** |
| 路由器 NAT-PMP | **没有** |
| Windows 防火墙 | 该网卡是 **Public** 档，默认阻入站 |
| STUN | **不稳定**：调研那一轮 6 个里成功 2 个（看到 `117.136.38.164`，与出口一致），但我随后连测 3 轮 **全部失败**（超时 / DNS 解析失败）。UDP 3478 大概率被中间设备干扰，**STUN 在这台机器上不可靠** |

> **结论不依赖 STUN**：判断有没有公网 IP，靠的是 `tracert` 第一跳 + `arp` + 光猫后台
> （硬证据），STUN 只反映 UDP 映射情况，而它在这台机器上时好时坏，不作数。

**结论**：出口 IP 是运营商的，**不属于你**。运营商到你家光猫之间还有一层 NAT，
你家光猫到你 PC 之间又一层 NAT。**没有 UPnP/NAT-PMP，PC 无法主动在路由器上开洞。**
再加 Windows 防火墙 Public 档默认阻入站 —— 这条路**走不通**，不用再花时间测。

> 之前我说"本地无法证实"，调研把这个问号坐实了：**是走不通，不是测不出来**。

## ⑤ 飞书当"异地手机端"（最省事的异地方案）

如果你只是想在**外面**（不在家）跟怀恩说话，**飞书就够了** —— 不用装任何东西，
飞书 App 本身就是手机端。

对比：

| | 局域网 PWA | 飞书 | 微信 iLink |
|---|---|---|---|
| 家里同一个 WiFi | ✅ 最快 | ✅ | ✅ |
| 出门在外 | ❌ | ✅ | ✅（私聊） |
| 要装东西 | 手机浏览器 | 飞书 App | 微信 + 扫码 |
| 稳定性 | 局域网内很稳 | 网络不稳时会延迟 | 未知 |
| 能带文件/图片 | ✅ | 取决于飞书适配器 | 取决于 iLink |

**推荐组合**：
**电脑用桌面版 + 家里用局域网 PWA + 出门用飞书**。三条都通，互为备份。

> ⚠️ 组网穿透（ZeroTier / Tailscale / Cloudflare Tunnel）**放最后**：
> 本机的 ZeroTier **是个坏壳**（`zerotier-cli info` 报权限拒绝，要先 takeown + icacls），
> 1.16+ 还必须注册中央账号建网络，而且默认 planet 在境外 —— 违反用户"不走境外"的约束，
> 要国内 moon 才行。加上蒲公英这类国内中继，是"实在没别的路"时的选项。
