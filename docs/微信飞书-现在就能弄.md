# 微信 / 飞书 —— 现在就弄

> 用户 2026-10-30: *"2的飞书和微信告诉我怎么弄，现在就弄。'hermes gateway setup'这个找不到。"*

## 一、"hermes gateway setup 找不到"的真相

**命令是存在的**（`hermes gateway --help` 里列着），但有两个坑：

### 坑 1：hermes 不在系统 PATH

```cmd
hermes gateway setup
→ 'hermes' 不是内部或外部命令
```

**修法**（已做成桌面双击）：
```
%LOCALAPPDATA%\AppData\Local\hermes\bin\hermes.exe gateway setup
```
或者用 **`桌面\怀恩-连接微信飞书.bat`** —— 它自动把 PATH 补上再进向导。

### 坑 2：向导要 TTY，管道喂不进去

实测 `hermes gateway setup` 的输出：

```
┌─────────────────────────────────────────────────────────┐
│             ☤ Gateway Setup                            │
├─────────────────────────────────────────────────────────┤
│  Configure messaging platforms and the gateway service. │
│  Press Ctrl+C at any time to exit.                     │
└─────────────────────────────────────────────────────────┘

✓ Gateway service is installed and running.

◆ Messaging Platforms
  No platforms configured. Run 'hermes gateway setup' when ready.
```

**"No platforms configured" 不是报错** —— 它说的是"平台配置里还没条目"。
**飞书现在能用**，是因为它走 `.env` 里的环境变量被自动启用的，**不登记在这个菜单里**。

**所以：用双击的 bat（有真实 TTY 窗口）进菜单，不要在 CMD 里敲。**

**注意**：现在有的是 `:readonly`（能读），缺的是**推送**（能收）。

### 你要做的三步

**第 1 步 —— 点这个链接授权**（浏览器打开，一键同意）：

```
https://open.feishu.cn/app/<FEISHU_APP_ID>/auth?q=im:chat:readonly,im:message:send_as_bot,im:message.p2p_msg,im:message.group_at_msg&op_from=openapi&token_type=tenant
```

**第 2 步 —— 发布新版本**（授权后必须做，否则不生效）

飞书开放平台 → 你的应用 → **版本管理与发布** → 创建版本 → 申请发布 → 通过。
> 只授权不发布 = 权限不生效。这是最常见的坑。

**第 3 步 —— 在飞书里给机器人发一条私聊消息**

打开飞书 → 搜 **Hermes-work** → 私聊发 `/help`。

## 三、微信 —— 扫码就行

### 前置（已全部就绪，实测）

```
aiohttp / cryptography / httpx / qrcode / PIL   →  全装好 ✅
hermes 可执行                                  →  在 ✅
```

**不用申请 appid、不用公网 IP、不用 webhook** —— 腾讯 iLink Bot API 走长轮询。

### 你要做的

1. 双击 **`桌面\怀恩-连接微信飞书.bat`**
2. 菜单里选 **Weixin**
3. **用手机扫终端里出现的二维码**（微信扫一扫）
4. 装完确认：`hermes gateway status` 里应有 weixin

### 微信的硬限制（官方行为，改不了）

| 能力 | 情况 |
|---|---|
| **私聊（DM）** | ✅ 可靠 |
| **普通微信群** | ❌ 基本不通 —— iLink 给的是**独立机器人身份**（`xxx@im.bot`），拉不进普通群 |
| 群机器人 webhook | ❌ 不支持 |
| 企业微信 | ❌ 要企业微信组织账号 + 管理后台建 Bot，个人走不通 |

**所以微信这条路，用户只能拿来做「私聊指挥怀恩」**，不能拉群。

## 四、连上之后，当前会话能看到吗？

**能。** 这是用户最关心的（"我还需要当前会话继续优化怀恩"）。

### 架构事实（实测）

```
$ hermes gateway list
  ✓ default (current)        — PID 18060
  ✓ auditor                  — PID 18060
  ✓ coder                    — PID 18060
  ✓ huaien                   — PID 18060
  ✓ researcher               — PID 18060
```

**所有 profile 共用一个 gateway 进程**（PID 相同）。
Hermes 强制单 gateway（`hermes gateway migrate` 的说明就是"把每个 profile 的
gateway 收敛到一个 host gateway"）。

### 两个层面

**① 微信/飞书的对话 → 落在 default profile 的同一个 state.db**

→ 当前会话用 `session_search` 直接搜得到，**而且能拿到可点击的会话链接**。

**② 怀恩前台的对话 → 在 huaien profile 的库**

→ 当前会话用 `session_search(profile="huaien")` **跨 profile 搜**（只读）。

### 实测（真的搜出来了）

```
session_search(query="怀恩可以干活", profile="huaien")
→ 3 条命中, 带完整消息 + 工具调用 + 可点击链接
   @session:<PROFILE>/<SESSION_ID>
```

**所以你在当前会话里可以直接问**：
- "我刚在微信里跟你说了什么" → 我搜给你看
- "怀恩前台昨天干了啥" → 我跨 profile 搜给你看

### 但有一条要说清楚

**它们是"同一个管家"，不是"同一条对话"。**
每个平台每个群/私聊有自己独立的 session（context 是隔离的，这是对的 ——
不然你在群里说的话会污染你的私聊）。
**共享的是同一个人的记忆和同一个 profile。**
