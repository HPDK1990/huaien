# 怀恩 V0.1.0 — 版本文档

> 一个纯黑、单对话框、无按钮的科技风前台。背后是本机 Hermes Agent 的独立人格。
> **它只跟你说话, 复杂的事都留在后台。**

## 1. 这是什么

**前台** — 一个 760×520 的纯黑窗口。没有标题栏, 没有菜单, 没有按钮。
你说一句, 它逐字答一句。

```
用一句话说: 你好          ← 灰色, 你说的
你好，用户，有什么需要我做的。  ← 白色大字, 管家说的

说点什么…▌                ← 会呼吸的光标
```

**后台** — 你本机的 Hermes Agent, 用独立 profile `huaien`。
人格写在 `~/.hermes/profiles/huaien/SOUL.md`: 话不多, 不展示过程, 只给结论。

## 2. 怎么用

双击桌面上的 **怀恩.bat**。

| 键 | 作用 |
|---|---|
| `Enter` | 发送 |
| `Esc` | 清空重开 (丢上下文) |
| `Ctrl+Q` | 退出 |

拖动窗口空白处可以移窗口。

## 3. 架构

```
怀恩窗口 (huaien/app.py)
   │  一句话
   ▼
ChatBridge (huaien/bridge.py)
   │  subprocess: hermes -p huaien chat -q "..." --format stream-json [--resume sid]
   ▼
逐字流式回来 → 打字机效果渲染
```

**三个技术选择 (以及没选的那些)**:

| 选择点 | 候选 | 选中 | 理由 |
|---|---|---|---|
| 怎么接 Hermes | A. CLI 子进程 / B. WebSocket JSON-RPC / C. 自建 OpenAI 兼容 server | **A** | B 的 RPC 契约不在公开文档里, 摸清成本高且脆; C 要额外进程 + 自维护协议层。A 是 Hermes 最稳定的接口面, 输出格式有保证。 |
| 界面放哪 | A. 独立窗口 / B. 塞进 Hermes dashboard / C. 重写 Electron | **A** | B 的 dashboard 已有官方 Kanban 页, 但那是给工程用的, 塞进去会破坏"只有一个界面"的要求。C 成本最高。 |
| 人格怎么隔离 | A. 独立 profile / B. 前台包一层提示词 | **A** | 后台 profile 带着"必须带自检行"这类工程格式契约, 前台不该看见。B 会污染对话历史。 |

## 6. 已知限制

1. **每轮对话起一个新 Hermes 进程**, 2-4 秒启动开销, 靠 `--resume` 续接上下文。
2. **前台与后台工程 profile 记忆隔离** (设计如此)。
3. **前台只显示最近一轮**对话, 全部历史去后台看板看。
4. **启动脚本 `.bat` 需 cmd 原生编码** (GBK/ASCII), 不能 UTF-8。
5. **Hermes gateway 必须活着** —— 它是后台的根, 停了前台就答不了话。`scripts/watchdog.py` 负责拉起来。
