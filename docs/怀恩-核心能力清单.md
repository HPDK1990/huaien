## 一、一段话摘要

**怀恩是一个"前台极简对话壳 + 一套管家判定规则 + 一整套自己写的运维脚本 + 四层测试塔"的个人助理系统**：桌面端是一块 780×560 的纯黑无边框单对话框，手机端是一个带 24 位随机口令的局域网 PWA，两端都通过 `huaien/bridge.py` 桥接 Hermes CLI 做流式对话和多轮续接；管家大脑 `scripts/butler.py` 按 `config/POLICY.md` 的 5 条规则判定"有没有事要你看"（判定逻辑本身可靠，实机正确命中了本机真实失败的 cron job），但**整条主动推送链路没有任何调度器在驱动**——根目录和全部 4 个 profile 的 `jobs.json` 里 `butler`/`flush_outbox` 零命中，所以"怀恩主动开口"目前只能靠人手敲命令；外部通道里**微信 iLink 是唯一完整闭环**（入站出站双向真发真收）——但必须说清楚：**通道本身是 Hermes gateway 的原生能力，怀恩侧零协议实现**（`scripts/` + `huaien/` 全文 `ilink` / `wss://` / `access_key` / `open.feishu` 均 0 命中，出站一律走 `hermes send` 子进程），怀恩自己实现的通道只有手机端 PWA（X-04）；飞书验过但极不稳定，局域网 PWA 机制正确但当前没在跑，webhook 是空壳，公网直连已定论走不通。
