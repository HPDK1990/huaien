## 三、两个硬约束（真实测出来的，模拟测不出来）

### 1. iLink 的 sendmessage session 有寿命 —— 连发约 3 条就废

```
1/4 纯文字  rc=0 sent
2/4 图片    rc=0 sent
3/4 视频    rc=0 sent
4/4 文档    rc=1  "iLink sendmessage session not ready: ret=-2 prepare failed —
                  the user must send the bot a message first (or re-pair)"

退避无效: 等 45 秒 / 20 秒 / 20 秒连试三次, 全是 -2
```

**不是频率限制**（退避无效），是**用户必须再发一条消息**才能复活 session
（那条消息会带新的 `context_token`）。

**不影响实际使用**：一问一答的回合里，agent 的回复走 gateway 的正常路径，
用的是最新 context_token —— 用户 13:05 那次要文件，怀恩带附件回的就是通的 ✅。

**影响主动推送**：连推多条会中途死。`scripts/wechat_send.py` 做了两件事：
- 每条之间留间隔（默认 8 秒）
- **识别 session 失效并立刻停止剩余发送**（继续发只会连续失败）

### 2. 微信 adapter 是**一个附件一条消息**

```python
# gateway/platforms/weixin/adapter.py
item_lists: list[list[dict]] = [[item_builder(**item_kwargs)]]
item_lists.insert(0, [{"type": ITEM_TEXT, ...}])
for item_list in item_lists:
    resp = await _send_items(...)
```

所以「一条推送带图+视频+文件」= 3 条消息 → 更容易撞 session 限制。
**要一次推多个附件，得合并成一个 zip 或让用户先发一条消息。**

## 四、微信 → 怀恩的人格路由

```
13:05:31  [Weixin] inbound from=<CHANNEL_ID> media=0
13:05:31  Flushing text batch agent:huaien:weixin:dm:<WECHAT_CHAT_ID>@im.wechat
```
`agent:huaien:...` → 走怀恩人格（`huaien` profile 的 SOUL.md），不是 default 的助手。

入站的图片会落到 **`profiles/huaien/cache/documents/native-inputs/`**（profile 自己的目录），
并自动转成给模型看的问题：`What do you see in this image? [Image attached at: ...]`。
