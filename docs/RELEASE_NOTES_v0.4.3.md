# 怀恩 v0.4.3

一个**极简的前台管家界面**：你只跟它说话，它把复杂的事都放到后台去。

- **前台** —— Python/Tkinter 写的单对话框窗口，纯黑、中文、极简科技风
- **后台** —— 你本机的 [Hermes Agent](https://github.com/NousResearch/hermes-agent)，带独立人格 profile：话不多，不展示过程，只给结论

前台只负责三件事：给你一个能打字的框、把后台的话显示出来、把回车变成一次 agent 调用。
模型、工具、记忆、会话库、看板、定时任务全部复用 Hermes 原生能力，前台不另造一套。

## 快速开始

| 场景 | 怎么做 |
|---|---|
| 电脑上用 | 双击 `scripts\启动怀恩.bat` |
| 手机上用 | 双击 `scripts\启动怀恩手机端.bat`，窗口里会打印一个带口令的网址，手机连同一个 WiFi 打开它，再"添加到主屏幕" |
| 手动 | `python -m huaien.app`（桌面）/ `python -m huaien.web`（手机端） |

> 手机端那个网址**等同于你的电脑权限**，不要转发给别人。

## 本版要点

### 上架隔离机制

日常开发与公开上传**物理分离**：开发仓库保留真实配置与运行态，公开副本由导出器自动脱敏生成。

```
开发仓库 ──export_public.py──▶ 中性公开副本 ──audit_publish.py──▶ 推送
                                    ▲                                  │
                                    └────── 有残留就当场拒绝 ──────────┘
```

- `scripts/export_public.py` —— 导出器，自动脱敏 500+ 处
- `scripts/publish_release.py` —— 一键发布：导出 → 审计 → 提交 → 推送（审计失败即停）
- `scripts/audit_publish.py` —— 上架审计器：扫工作区 + 全部 refs + 逐 commit 历史
- `scripts/install_audit_hook.py` —— pre-commit 本地钩子
- `.github/workflows/audit.yml` —— CI 强制审计（任何人 fork/PR 进来都拦得住）

三道闸独立生效：本地钩子、导出后自检、CI 审计。

### 敏感信息审计

覆盖：API key / 令牌 / 聊天 ID / 内网 IP / 机器专属路径 / 个人称呼 / 私钥头 / 手机号 / 邮箱。

设计原则：

- **审计输出永不打印真值** —— 只显示掩码、规则和位置，避免审计日志成为二次泄露
- **不靠"猜内容"判断真假凭据** —— 真凭据与测试夹具的判定靠上下文（文件类型 + 假前缀 + 明显编造序列），而不是看尾部像不像 abc 连续段
- **导出后自检用独立编码源** —— 脱敏规则与自检源各用一套字符码表示，两边同时写错的概率极低

### 修掉的问题

| 症状 | 根因 | 修法 |
|---|---|---|
| CI 连续红而本地全绿 | Windows 上 Python 输出走 locale 编码，中文/emoji 触发 `UnicodeEncodeError` | 脚本自己接管 stdout 编码；workflow 加 `PYTHONUTF8=1` |
| 公开副本残留个人称呼 | 脱敏规则的字符码写错一位，规则匹配不到任何东西 | 字符码修正 + 导出后自检 + 审计器加称呼规则 + 4 项测试锁死 |
| 24 位 hex 规则漏报 | 负向前后看会漏掉长 hex 串里中段的真令牌 | 窗口法，只在上下文含 commit/sha/git/HEAD/rev 时豁免 40 位串 |
| 审计目标判断错误 | 靠 cwd 猜审计对象，无 `.git` 的导出目录会回退到源仓库 | 加 `--root` 显式指定 |
| 封存包混入自检截图 | 封存脚本复制全部 `docs/*.png`，而自检截的是整屏 | 截图改落 `logs/`，封存改白名单 |
