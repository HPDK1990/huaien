# 怀恩 · 主动行动规则（机器可读版）

> **用户定的规矩。改这个文件就改了怀恩的行为，不用重启任何东西。**
>
> 格式: `- [规则ID] 说明文字`。规则ID 对应 `scripts/butler.py` 里的检查器。
> **没写在这里的，管家大脑不会主动开口。**
>
> 人读的完整版在 `%LOCALAPPDATA%\AppData\Local\hermes\profiles\huaien\POLICY.md`
> （那份是给 agent 自己看的，这份是给脚本执行用的，两者语义必须一致）。

## 一、脚本能自动判定的（`butler.py` 执行这些）

- [blocked] 看板出现 blocked/failed 状态的卡 → 推卡标题、卡号、卡住原因
- [cron-fail] 定时任务最近一次失败 → 推哪个任务、失败原因、已经做了什么处置
- [backup-fail] 每周五的备份任务失败 → 立即推微信
- [db-size] 会话库体检体积超过 500 MB → 推实际体积、涨了多少、建议动作
- [gateway-down] gateway 心跳超过 3 分钟没动（它死了前台就答不了话）→ 推微信

## 二、只有 agent 能判定的（由怀恩自己在会话里读 profile 那份 POLICY.md 判断）

- 用户交代的长活做完了 → 结果一句话 + 产物路径
- 多 agent 编排的一批任务全部完成 → **一次**汇总，不要每张卡推一次
- 看板有卡完成，且是用户**当天**交代过的那件事

## 三、必须安静

- 用户正在跟他说话 → 不插话
- 一切正常、没有 blocked、没有失败 → **不推"一切正常"**
- 刚才已经推过同样的内容 → 不重复推
- 一次最多推一条，别刷屏
- 推微信失败（iLink session 失效）不重试刷屏 → 存进 outbox，等用户发过消息再补发
